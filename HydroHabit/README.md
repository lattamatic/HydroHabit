# 💧 HydroHabit - Smart Hydration Tracker

An iOS 18 application built with **SwiftUI** and **SwiftData** that calculates your ideal water intake and sends smart notifications that avoid mealtimes and sleep.

## ✨ Features
- **3D Interactive UI:** A tapered, realistic water glass that fills as you drink.
- **Smart Reminders:** Logic-based notifications that automatically pause 45 minutes after meals and during your sleep window.
- **Dual-Profile System:** Seamlessly switch between a Primary User and a Demo Profile.
- **One-Click Demo:** Populates 15 days of historical data with a single tap to showcase the dashboard instantly.
- **Monthly Analytics:** A full calendar view with "Success Drops" and a large progress dashboard.

## 🛠 Tech Stack
- **Framework:** SwiftUI
- **Database:** SwiftData (Local persistence)
- **Architecture:** MVVM + Repository Pattern (Cloud-ready)
- **iOS Version:** iOS 17.0+
